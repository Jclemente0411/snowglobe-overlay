# SnowGlobe Overlay

Android Christmas overlay prototype. Keeps the existing wallpaper and icons; draws touch-through falling snow and blinking Christmas lights above ordinary apps.

## Build
Open this repository's Actions tab and run **Build Android APK**, or push to main. Download the `SnowGlobe-debug-apk` artifact after a successful build.

## Install
Install the debug APK on an Android phone. Open SnowGlobe, grant **Display over other apps**, and tap **Start snow**. Use **Stop snow** to remove the overlay. This is a prototype; Android may hide overlays on sensitive screens, and lock-screen overlays are not guaranteed.

## Privacy
No network access, analytics, or account needed. The overlay does not intercept touches.
